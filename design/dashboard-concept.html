About this concept

A design proposal, not the working dashboard. Nothing here is wired to the app, and this file is outside the installer’s file list so it can never ship. Content is real: the etalase, triggers, replies and the timings in Activity are from the validated run on 9 October. The account name is deliberately not the real test account.

Green means one thing
Running, or on air. Nothing else is green — not “connected”, not “available”, not “saved”. That is why there is no brand accent colour competing with it.
The state is a sentence
“The bot is not running”, at the top, next to the only control that changes it. Today that answer is split across a pill, a checklist row and a third card.
Ordered by when it matters
Status and etalase first because that is what you watch mid-broadcast; the pre-start checks disappear once the bot is running.
The numbers are yours
Etalase 1–5 is the shop’s own numbering, so it is used as structure. The chain in Activity is a real sequence, drawn with a connector rather than decorative numbering.
If you adopt it
Every element id and class hook the page script relies on stays as it is. The one real cost is the typeface: the app loads nothing from the network by design, so IBM Plex Sans means self-hosting one subset file of roughly 30 KB. On Segoe UI Variable the design still holds.
Still open
A dark theme. You work beside OBS, which is dark, but the app has only ever been light — worth deciding rather than assuming.
